# Kit identity

Container lengths were fixed before note generation. Every core part is 8 bars. Every arrangement is 32 bars. Meter is 4/4. No stochastic draws.

Rhythmic interaction, motif development, controlled harmonic movement, and instrumental dialogue. The BPM range is a project choice, not a claim that these files are authentic genre productions.

Core versus reference: There is no reference-only part. All five roles are core. The arrangements reuse those files.
