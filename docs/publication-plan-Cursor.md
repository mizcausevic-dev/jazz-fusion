# Publication plan

Status: prepared for GitHub Pages on the gh-pages branch. Treat the address as live only after it responds.

The GitHub repository is https://github.com/mizcausevic-dev/jazz-fusion and it is public. The catalog address is https://mizcausevic-dev.github.io/jazz-fusion/ .

## What is local

The MIDI, matched validation report, MP3 (18.495 s), MP4, VTT, raster stills, drafts, page, and README are produced by `python3 tools/build_pack.py`. Draft labels do not hide files. A public remote makes the drafts public.

## What this build does not do

No release tag is created. Nothing is posted to Medium, Instagram, or X. The catalog address is the GitHub Pages URL in the publication line. If Pages cannot be enabled, that URL returns 404 until an admin sets the gh-pages branch as the Pages source.

## Prepared metadata

Description: Original note-only MIDI construction kits for jazz fusion, with matched validation and a simple-synth preview.

Topics: midi, jazz-fusion, music-production, composition, harmony.

`index.html` is the Pages entry. `media.html` is the screening room. Pages should serve the gh-pages branch at the repository root.

## Security note for a later deploy

The page is static. It has no form, no account system, and no secret. It links to MIDI and media in the same tree. A later deploy should not add a checkout or a lead form without a separate privacy review.
